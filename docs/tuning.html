Lua or JavaScript, per system

Inventory, jobs, vehicles and money exist in both your Lua resources and fourtune. world and fourtune also both claim /whereami, /places and /cities. Run both and each command registers twice, with the second silently losing.

Whether the cars get renamed too

Guns, shops and streets moved off Rockstar’s names. Vehicles didn’t, because GTA draws its own name on screen when you get in — renaming Karin Sultan would make chat and the game disagree.

The one blocker

Everything in-game waits behind this.

The API isn’t in the repo, so nothing saves

fivem-server.js has TODOs where loading and saving go. Run node tools/join-server.js <path> on your PC and characters start persisting. Until then every session starts fresh.

Check on the first boot

Cheap to look at while you’re in there.

files{} ships server logic to players

fourtune lists its server modules there so require() can reach them, but that also sends them to every connecting client. If require() still works without those entries, drop them.

Does world load without lua54?

It uses nothing version-specific, so it should run either way. If it throws on load, that’s the first thing to try.

Everything above is on main. 89 JavaScript checks and 84 Lua checks pass headlessly — and none of it has ever run inside FXServer, so the first boot is still the real test.
