# Walk list — real coordinates for the maps and the game

_Generated by `node tools/gen-walk-list.js > docs/WALK-LIST.md` from `js-snippets`. Don't edit by hand: fix the data, then regenerate._

Every number below is a **placeholder** (a first guess, not a walked spot). Walk each one in game,
capture the real position, and paste it into the file named next to it. When the list is done, the
game's naming (`/whereami`, dispatch, the HUD), the atlas and the big map all line up.

## How to capture

1. Start the server with the `fourtune` resource (see `docs/NEXT-ON-PC.md`).
2. Stand on the spot. For a **pin**, stand where the player should interact (the counter, the pump, the door).
   For a **road**, stand on the centre line.
3. Type `/mark <name>`. It replies with the position ready to paste, for example:
   `MARK Alder Street bend: { x: -269.4, y: -955.3, z: 31.2 }  (atlanta)`
4. Screenshot the chat or copy the line, and tick the box here.
5. `/whereami` shows which road, park or district the game thinks you're in, which is a quick check once a section is pasted in.

### Roads: what to mark

- Drive each road **start to end** and `/mark` the start, **every real bend or junction**, and the end.
  2 points for a straight road; add one wherever the road turns more than a little.
- Where two roads meet, mark the **same spot** for both, so they join on the map.
- `kind` stays as it is unless the road is clearly bigger or smaller than listed (highway, arterial, street, backroad).
- Ring roads (The Perimeter, Knot Loop): mark around the loop and repeat the first point at the end to close it.

### Zones: what to mark

- Districts and parks are circles: mark the **centre**, then walk to the edge and mark again.
  The radius is the distance between the two (or just estimate it in game units: about a metre each).

## When the list is done

```
node --test js-snippets/game.test.js             # still green
node tools/gen-world-data.js > world/data.lua    # the Lua world layer
node tools/gen-map.js > docs/city-map.html       # the atlas
node tools/gen-map-detail-layer.js               # the big map's roads, pins and legend
node tools/gen-walk-list.js > docs/WALK-LIST.md  # this list, with the new numbers
```

Then tell Claude the coordinates are walked: the big map's 13 hand-drawn main roads get replaced by the
walked ones, and the towers, stations, cars and road wear get re-placed against them.
